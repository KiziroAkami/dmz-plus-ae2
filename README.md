# DMZ Plus AE2

Compatibility bridge between [DragonMineZ](https://www.curseforge.com/minecraft/mc-mods/dragonminez)
and [Applied Energistics 2](https://www.curseforge.com/minecraft/mc-mods/applied-energistics-2)
for Minecraft 1.20.1 (Forge). Part of the [DMZ Plus](https://github.com/KiziroAkami/dmz-plus) family.

## Features

- **Meteorite exclusion** — AE2 meteorites are vetoed within a configurable chunk radius
  (`compat.exclusionChunks`, default 4) of DragonMineZ's planned unique structures, so a
  crater can never destroy a one-of-a-kind landmark like Goku's House or the Cell Arena.

## Requirements

- Minecraft 1.20.1, Forge 47+
- DragonMineZ 2.1.1+
- Applied Energistics 2 15.x
